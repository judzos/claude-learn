How a lesson runs

Run /learn:teach <topic>. The lesson note opens in Obsidian and fills in as you go.

Find where it runs out

Claude makes your goal concrete, then binary-searches each strand it depends on for a floor you get right and a ceiling you don't.

learn quiz, probe

1 in 1000 people have a disease. A test catches 99% of cases, with 1% false positives. You test positive. Chance you're sick?

  1. About 99%
  2. About 50%
  3. About 9%
  4. I don't know

✗ About 99%, you were 95% sure. Correct: about 9%.

Check every step

Each step runs predict, teach, check. After each answer you say how sure you were and what you were thinking.

learn quiz, check on base rates

1000 people take that test. About how many of them test positive?

1 true positive plus about 10 false positives. The rare condition sets the odds.

Keep what you learned

Propositions and the chains between them go into a knowledge graph in your Obsidian vault, and later lessons build on it.

graph/nodes.jsonl

  • + A rare condition makes most positives false.
  • + P(A | B) = P(B | A) P(A) / P(B)
  • chain both of these entail: a 99% test can mean 9%

Practice that never names the idea

/learn:practice poses problems where what you learned has to come to mind on its own.

A hidden answer
Claude solves each problem first and shows the solution only after it's concluded.
Six rungs of hints
From “re-read the givens” to a worked step, one rung per request.
Retests
Anything missed comes back in a new form before the session ends.

Five commands to know

CommandWhat it does

/learn:practice [topic]Problems on what you already learned
/mapShow the lesson's plan map
/graphAdd this session to the knowledge graph
/md-log <note.md>Mirror the session into an Obsidian note

/learn prints the full list.

Built on LearnHarness

LearnHarness is Amos Blomqvist's open-source desktop app for learning with AI. This plugin brings its method into Claude Code.

Get the LearnHarness app
Kept
The teaching, probing, practice and extraction prompts, and the graph format.
Changed
Runs on a Claude subscription instead of API keys. Quizzes use Claude Code's popup, and background jobs are subagents.
Left out
The cost meter, dictation and the in-app updater.

Install it

Then run /learn:teach with any topic.

  1. At the Claude Code prompt

    /plugin install learn --marketplace judzos/claude-learn

    Answer y to add the marketplace, then pick a scope.

  2. From a shell

    claude plugin install learn --marketplace judzos/claude-learn

  3. In the desktop app

    Click + next to the prompt box, then Plugins. Add the marketplace judzos/claude-learn, then add the plugin.

Diagrams need rsvg-convert or ImageMagick, and Node for Mermaid. Interactive demos need Node and Chrome or Chromium.
